# Suplan análisis de proveedores V0

## Veredicto

No conviene empezar con personalización cápsula a cápsula. El MVP físico debería usar packs predefinidos recomendados por quiz y sobres mañana/tarde.

## Categorías necesarias

- CDMO/private label de complementos alimenticios.
- Co-packer de sobres/sachets si el fabricante no ensobra.
- Laboratorio externo para QA.
- 3PL con lotes, caducidad y suscripción.
- Regulatory/QA para claims, etiquetas y notificación.

## Preguntas RFQ críticas

- ¿Fabricáis complementos para terceros/private label?
- ¿Podéis producir sobres diarios con varias cápsulas/comprimidos dentro?
- ¿Podéis separar mañana/tarde?
- ¿MOQ por fórmula y formato?
- ¿Lead time de muestras, primer lote y reposición?
- ¿Certificaciones vigentes: GMP, ISO 22000, FSSC 22000, HACCP, IFS/BRC?
- ¿CoA por lote y análisis de microbiología/metales/alérgenos?
- ¿Soporte para claims, etiquetado y notificación España/UE?
- ¿Trazabilidad lote → pedido → cliente?
- ¿Material de sobre apto para contacto alimentario y con barrera suficiente?

## Riesgo principal

El cuello de botella no es fabricar cápsulas. Es ensobrar múltiples cápsulas por cliente/día con trazabilidad, estabilidad, control de conteo y coste razonable.
